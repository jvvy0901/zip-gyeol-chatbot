# 부동산 기초 용어

처음 집을 구하는 사용자를 위한 쉬운 설명이에요. 🧪 일반 상식 수준의 설명이고, 법률 · 세금 조언은 아니에요.

## 거래 유형 (집결 필터에 있는 3가지 ✅)

| 용어 | 뜻 | 집결 가격 표시 |
|---|---|---|
| **전세** | 큰 보증금을 맡기고 매달 월세 없이 사는 방식. 나갈 때 보증금을 돌려받아요 | `2억 2,000만` |
| **월세** | 보증금(작은 목돈) + 매달 내는 월세 | `1,000만 / 월 65만` |
| **매매** | 집을 사는 것 | `6억 8,000만` |

## 돈 관련

| 용어 | 뜻 |
|---|---|
| 보증금 | 집주인에게 맡기는 돈. 계약이 끝나면 돌려받아요 |
| 관리비 | 건물 청소 · 공용 전기 · 수도 등에 매달 내는 돈. 무엇이 포함되는지 꼭 확인해요 |
| 만원 단위 | 집결의 가격 · 예산은 모두 만원 단위예요. `10000` = 1억, `5000` = 5천만 ✅ |
| 중개 수수료(복비) | 공인중개사에게 내는 수수료. 거래 금액에 따라 상한이 정해져 있어요 |
| 전세보증보험 | 집주인이 보증금을 못 돌려줄 때를 대비한 보험 |

## 넓이 · 구조

| 용어 | 뜻 |
|---|---|
| ㎡ (제곱미터) | 집결이 쓰는 면적 단위 ✅ |
| 평 | 옛 단위. **1평 ≈ 3.3㎡**. 39.6㎡ ≈ 12평 |
| 원룸 · 투룸 · 쓰리룸 | 방 1 · 2 · 3개. 집결에서는 "방 N개"로 표시해요 ✅ |
| 복층 | 한 집 안에 위아래 두 층. 위층 천장이 낮은 경우가 많아요 |
| 오피스텔 | 업무 · 주거 겸용 건물. 관리비가 높은 편이에요 |
| 빌라 | 4층 이하 공동주택. 엘리베이터가 없는 경우가 많아요 |
| 남향 | 창이 남쪽. 해가 오래 들어 겨울에 따뜻해요 |

## 집 구하기 과정

| 용어 | 뜻 |
|---|---|
| **임장** | 집을 직접 보러 가는 것. 집결은 "온라인 임장"을 도와요 ✅ |
| 풀옵션 | 세탁기 · 냉장고 · 에어컨 등 가전이 갖춰진 집 |
| 등기부등본 | 집 주인 · 대출(근저당) 여부가 적힌 서류. 계약 전에 꼭 확인해요 |
| 확정일자 · 전입신고 | 세입자가 보증금을 지키기 위해 주민센터에서 하는 신고 |
| 역세권 | 지하철역에서 걸어서 10분 안쪽 |
| 학군지 | 학교 · 학원이 모여 있어 학부모 선호가 높은 동네 |
