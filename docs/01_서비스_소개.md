# 서비스 소개 — 집결

## 한 줄 소개 ✅

> **원하는 집 정보가 여기로 집결**
> 지금, 집결과 함께 온라인으로 임장해 보세요.

집결은 집에 직접 가 보기 전에 **집 안을 3D로 걸어 볼 수 있는** 가상 부동산 서비스예요.
조건을 남기면 코디가 맞는 집을 추천하고, 추천받은 집을 3D(가우시안 스플래팅)로 둘러볼 수 있어요.

- 서비스 이름: 집결 (영문 ZIPGYEOL)
- 이름 뜻: "집"과 "집결(모이다)"을 합친 말. 원하는 집 정보가 한곳에 모인다는 뜻이에요.
- 메인 색: 파란색 `#0056FF` — 신뢰와 편리함

## 할 수 있는 일 ✅

| 기능 | 설명 | 주소 |
|---|---|---|
| 집 안 둘러보기 | 직접 가 본 것처럼 집 안을 3D로 둘러봐요 | `/listings/<번호>` |
| 조건으로 찾기 | 동네와 조건만 고르면 맞는 집을 바로 보여 드려요 | `/listings` |
| 찜 · 비교 | 찜한 집을 나란히 놓고 한눈에 비교해요 | `/wishlist` |
| 의뢰서 남기기 | 원하는 조건을 남기면 코디가 맞는 집을 찾아 드려요 | `/request` |

## 누가 쓰면 좋을까요 🧪

| 사용자 | 이런 분께 좋아요 |
|---|---|
| 첫 자취를 준비하는 대학생 | 관악구 · 성동구 원룸을 3D로 미리 보고 발품을 줄이고 싶을 때 |
| 이직 · 전근하는 직장인 | 강남역 · 성수역 근처 집을 퇴근 후 온라인으로 먼저 보고 싶을 때 |
| 신혼부부 | 투룸 전세를 여러 개 찜해서 나란히 비교하고 싶을 때 |
| 아이 있는 가족 | 학군 · 조용한 동네의 쓰리룸 · 아파트를 찾을 때 |
| 지방 · 해외에서 서울로 이사 오는 분 | 직접 임장하기 어려워 온라인 임장이 필요할 때 |

## 지금 서비스 범위 ✅

- 지역: 서울 **마포구 · 성동구 · 강남구 · 관악구** 4곳
- 매물 수: **12개** (모두 가상 매물)
- 거래 유형: 전세 · 월세 · 매매
- 3D 둘러보기: 현재 **1번 매물(햇살 드는 망원동 투룸)** 만 가능. 나머지는 사진으로 보고 3D는 준비 중이에요.
- 로그인 없음: 찜은 지금 쓰는 브라우저에만 기억돼요.

## 집결의 약속 🧪

1. **실명 · 연락처를 받지 않아요.** 닉네임만으로 의뢰할 수 있어요. (✅ 실제 규칙)
2. **보이는 그대로 보여 드려요.** 3D는 실제 공간을 찍어 만든 것이라 사진보다 크기 · 구조가 정확해요.
3. **허위 매물 없이.** 등록 전에 코디가 매물 정보를 한 번 더 확인해요.
