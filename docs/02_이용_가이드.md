# 이용 가이드 — 페이지별 사용법

모든 내용은 ✅ 실제 서비스 동작이에요. (출처: `pages/*.py`, `templates/*.html`)

상단 메뉴: **매물 보기** · **의뢰서 남기기** · **찜** (찜한 개수가 배지로 보여요. 100개 이상이면 `99+`)

---

## ① 홈 `/`

- 메인 배너: "원하는 집 정보가 여기로 집결"
- **검색창**: 지역 이름을 쓰면 매물 목록으로 이동해요. 자동 완성에 실제 지역 이름(마포구 · 성동구 · 강남구 · 관악구)이 나와요.
  - 지역 이름은 정확히 같아야 찾아요. "마포"가 아니라 **"마포구"** 로 써야 해요.
- 기능 카드 3개: 집 안 둘러보기 / 조건으로 찾기 / 찜 · 비교
- **대표 매물**: 매물 3개를 보여 줘요. (지금은 번호 순 앞의 3개)

---

## ② 매물 보기 `/listings`

동네와 조건으로 찾고, 마음에 들면 3D로 미리 둘러보는 곳이에요.

### 필터 4가지

| 필터 | 고르는 법 | 동작 |
|---|---|---|
| 지역 | 목록에서 선택 | 그 지역 매물만 |
| 거래 유형 | 전세 / 월세 / 매매 | 그 유형만 |
| 최대 가격 | 숫자 (만원) | **보증금 또는 매매가**가 이 값 이하인 매물. 월세 금액은 기준이 아니에요 |
| 방 수 | 숫자 | 이 수 **이상**인 매물 |

- 빈 칸은 "조건 없음"으로 봐요.
- 필터는 주소에 남아요. 예: `/listings?region=마포구&deal_type=전세&max_price=30000&rooms=2` → 이 주소를 공유하면 같은 결과가 보여요.
- 결과 개수가 "매물 N개"로 보여요.
- 결과가 없으면 "조건에 맞는 매물이 없어요. 조건을 조금 넓혀서 다시 찾아보세요."가 나와요.
- 카드의 하트를 누르면 페이지 이동 없이 바로 찜돼요. 필터와 스크롤 위치도 그대로예요.

### 자주 막히는 점

- **"30000"은 3억이에요.** 가격은 모두 만원 단위예요. (1억 = 10000)
- 월세 매물을 "월 60만 이하"로 찾는 필터는 없어요. 최대 가격은 보증금 기준이에요.

## ③ 매물 상세 `/listings/<번호>`

- 위쪽: 3D 뷰어 (3D가 있는 매물) 또는 대표 사진 + "3D 둘러보기는 준비 중이에요"
- 요약 카드: 제목 · 지역 · 거래 유형 배지 · 가격 · **찜하기** · **의뢰하기** 버튼
- 탭: **정보**(방 · 면적 · 층, 집 소개) / **평면도**(3D가 있는 매물만)
- 가격 표시 예: `2억 2,000만`, 월세는 `1,000만 / 월 65만`
- 없는 번호(예: `/listings/999`)로 들어가면 "없어요" 404 화면이 나와요.
- 3D 조작법은 [03_3D_둘러보기.md](03_3D_둘러보기.md)를 봐요.

## ④ 의뢰서 남기기 `/request`

원하는 조건을 남기면 맞는 집을 찾아 드려요. **실명과 연락처는 받지 않아요.**

| 단계 | 질문 | 칸 |
|---|---|---|
| 1 | 어떻게 불러 드릴까요? | 닉네임 |
| 2 | 어떤 집을 찾으세요? | 희망 지역 · 예산 · 방 수 |
| 3 | 더 바라는 점이 있나요? | 요청 내용 |

- 쓰는 동안 오른쪽 "내 의뢰서" 카드가 같이 채워져요.
- 예산을 쓰면 아래에 "2억 5,000만원까지"처럼 읽기 쉬운 말로 보여 줘요.
- 보내면 "의뢰서가 접수됐어요"가 한 번 떠요. 새로고침해도 두 번 저장되지 않아요.
- 틀린 칸이 있으면 "N곳을 다시 확인해 주세요. 쓴 내용은 그대로 있어요."가 뜨고, 칸 옆에 이유가 나와요.
- 아래 "최근 의뢰서"에 최근 6개가 보여요. (닉네임 · 지역 · 예산 · 방 수 · 요청 내용)
- 자세한 규칙은 [06_의뢰서와_코디.md](06_의뢰서와_코디.md)

## ⑤ 찜 · 비교 `/wishlist`

마음에 둔 집을 나란히 놓고 비교하는 곳이에요.

- 찜하기: 목록 카드의 하트, 또는 상세 화면의 **찜하기** 버튼. 다시 누르면 찜 취소.
- 찜 목록: 찜한 매물이 모두 보여요.
- **나란히 비교하기**: 한 번에 **최대 3개**. 고르지 않으면 앞의 3개를 비교해요.
  - "비교할 매물 고르기"에서 체크해서 바꿀 수 있어요. 3개보다 많이 고르면 앞에서부터 3개만 비교해요.
- 비교 표에서 가장 좋은 값을 강조해요.
  - 면적: 가장 넓은 집
  - 방 수: 가장 많은 집
  - 가격: 가장 싼 집 — **단, 거래 유형이 모두 같을 때만**. 전세 · 월세 · 매매가 섞이면 가격은 강조하지 않아요.
  - 월세: 모두 월세일 때 가장 싼 월세
  - 값이 모두 같으면 강조하지 않아요.
- 찜이 1개뿐이면 "매물을 하나 더 찜하면 나란히 비교할 수 있어요."가 보여요.
- 찜이 0개면 "아직 찜한 매물이 없어요."가 보여요.

### 찜이 사라졌어요?

찜은 로그인 없이 **이 브라우저**에만 기억돼요.
- 시크릿 창 · 다른 브라우저 · 다른 기기에서는 0개가 정상이에요.
- 브라우저 쿠키를 지우면 찜도 지워져요.
- 매물이 내려가면 찜 목록에서도 자동으로 빠져요.
