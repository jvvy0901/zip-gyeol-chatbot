# 의뢰서와 코디

## 의뢰서란? ✅

원하는 조건을 남기면 **코디**가 맞는 집을 찾아 추천해 주는 신청서예요. 주소: `/request`
실명 · 전화번호 · 이메일은 받지 않아요. 닉네임만 있으면 돼요.

## 칸별 규칙 ✅ (출처: `validate.py`, `db.py`)

| 칸 | 규칙 | 예시 | 틀렸을 때 문구 |
|---|---|---|---|
| 닉네임 | 1~20자, 전화번호 모양 금지 | `이사준비` | "닉네임은 1~20자로 써 주세요." / "전화번호는 받지 않아요. 닉네임만 써 주세요." |
| 희망 지역 | 1~20자, 자유롭게 | `마포구` | "희망 지역은 1~20자로 써 주세요. (예: 마포구)" |
| 예산 | 숫자만, 만원 단위, 1 ~ 1,000,000 (=100억) | `20000` (=2억) | "예산은 숫자만 써 주세요. (예: 20000)" / "예산은 1만원부터 1,000,000만원(100억)까지 쓸 수 있어요." |
| 방 수 | 1~5 중 선택 | `2` | "방 수는 1~5 중에서 골라 주세요." |
| 요청 내용 | 1~200자, 전화번호 모양 금지 | `햇빛이 잘 드는 집이면 좋겠어요.` | "요청 내용은 1~200자로 써 주세요. (지금 N자)" / "전화번호는 받지 않아요. 지우고 다시 남겨 주세요." |

### 자주 틀리는 것 ✅

- **예산에 쉼표 · 글자 넣기**: `2억`, `20,000` 은 안 돼요. `20000` 처럼 숫자만.
- **예산 단위**: 만원이에요. 2억이면 `20000`, 5천만이면 `5000`.
- **전화번호 남기기**: `010-1234-5678`, `01012345678` 같은 모양이 닉네임 · 요청 내용에 있으면 막혀요. 개인정보 보호를 위해서예요.
- **방 6개 이상**: 선택지는 5까지예요. 더 필요하면 요청 내용에 써 주세요.
- 틀려도 **쓴 내용은 그대로 남아요.** 틀린 칸만 고쳐서 다시 보내면 돼요.

## 접수 뒤 ✅

- "의뢰서가 접수됐어요"가 한 번 떠요.
- 새로고침해도 두 번 저장되지 않아요.
- 화면 아래 **최근 의뢰서**에 내 의뢰서가 보여요. (최근 6개, 닉네임 · 지역 · 예산 · 방 수 · 요청 내용 · 시각)
  - ⚠️ 최근 의뢰서는 **다른 사용자에게도 보여요.** 요청 내용에 주소 · 이름 등 개인 정보를 쓰지 않도록 안내해요.
- 의뢰서는 수정 · 삭제 기능이 없어요. 바꾸고 싶으면 새로 남겨 주세요. 🧪 코디는 같은 닉네임의 최신 의뢰서를 기준으로 봐요.

## 코디가 하는 일 🧪

코디는 집결의 매물 추천 담당자예요.

1. **의뢰서 확인** — 영업일 기준 1~2일 안에 확인해요.
2. **조건 맞추기** — 지역 · 예산 · 방 수로 먼저 고르고, 요청 내용(햇빛 · 반려동물 · 역세권 등)으로 순위를 매겨요.
3. **추천 공개** — 추천 결과는 서비스 공지 · 최근 의뢰서 영역에서 닉네임으로 안내해요. (연락처를 받지 않기 때문이에요)
4. **3D 우선** — 추천한 집 중 3D가 없는 곳은 촬영 순서를 앞당겨요.

> ⚠️ 위 추천 공개 방식은 가상 설정이에요. 현재 코드에는 코디 답변 화면이 없어요. 챗봇은 "언제 · 어떻게 연락 오나요?"에 이 설정을 쓰되, 팀이 실제 방식을 정하면 이 부분을 고쳐요.

## 요청 내용 잘 쓰는 팁 🧪

- 꼭 필요한 것 1~2개를 먼저: "반려묘 있어요", "엘리베이터 꼭"
- 출퇴근 · 통학 장소: "강남역까지 30분 안"
- 입주 시기: "12월 말 입주"
- 피하고 싶은 것: "1층 · 반지하 제외"

예: `고양이 한 마리 있어요. 12월 중순 입주, 2호선 역에서 걸어서 10분 안이면 좋겠어요.`
