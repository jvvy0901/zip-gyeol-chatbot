## 정보 출처 표시

문서 안의 정보는 두 종류예요. 챗봇이 답할 때 섞이지 않게 표시해 뒀어요.

| 표시 | 뜻 | 근거 |
|---|---|---|
| ✅ **실제** | 지금 서비스 코드·데이터에 있는 정보 | `data/listings.csv`, `pages/*.py`, `validate.py`, `templates/*.html`, `DB_구조.md`, `README.md` |
| 🧪 **임의** | 챗봇 시연을 위해 새로 만든 가상 정보 | 없음 — 서비스에 반영하려면 팀 확인 필요 |

> 매물 자체가 가상 데이터예요. 🧪 표시는 "가상 매물에 덧붙인 가상 정보"라는 뜻이에요.
> 🧪 정보를 실제 서비스에 넣으려면 `data/listings.csv` 칸을 늘리거나, 챗봇 쪽 데이터로만 쓰기로 팀에서 정해야 해요.
