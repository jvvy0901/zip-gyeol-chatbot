# 3D 둘러보기

## 3D가 뭐예요? ✅

실제 집을 여러 각도에서 찍어 **가우시안 스플래팅**이라는 기술로 만든 3D 공간이에요.
사진처럼 보이지만 안을 걸어 다니며 원하는 방향을 볼 수 있어요. 홈 화면 문구로는 "직접 가 본 것처럼 집 안을 둘러봐요."

## 어떤 매물에서 볼 수 있어요? ✅

- 지금은 **1번 「햇살 드는 망원동 투룸」** 하나만 3D가 있어요. (3D 데이터는 샘플 공간으로 시연해요)
- 3D가 있는 매물은 지역 옆에 `360° 3D` 표시가 붙어요.
- 나머지 매물은 대표 사진과 "3D 둘러보기는 준비 중이에요"가 보여요.
- 🧪 3D 촬영은 순서대로 진행 중이며, 2026년 12월까지 6개 매물에 추가할 예정이에요.

## 조작법 ✅

| 하고 싶은 것 | 마우스 · 터치 | 키보드 (3D 화면을 한 번 누른 뒤) |
|---|---|---|
| 둘러보기 (고개 돌리기) | 드래그 | ← → 방향키 |
| 앞 · 뒤로 걷기 | — | ↑ ↓ 방향키 또는 W · S |
| 옆으로 걷기 | — | A · D |
| 원하는 곳으로 이동 | **바닥**을 누르기 | — |
| 지도에서 이동 | 오른쪽 **미니맵**의 원하는 곳 누르기 | — |

화면 아래 안내: "드래그해서 둘러보고, **바닥**이나 **미니맵**을 눌러 이동해요"

### 버튼 3개

| 버튼 | 하는 일 |
|---|---|
| 처음 위치 | 시작했던 자리 · 방향으로 돌아가요 |
| 넓게 보기 | 시야를 넓혀서 방 전체를 한 번에 봐요 |
| 크게 보기 | 3D 화면을 크게 키워요. **Esc**로 원래대로 |

### 미니맵 · 평면도

- 미니맵에 지금 내 위치가 점으로 보여요.
- 상세 화면의 **평면도** 탭에서 집 전체 구조를 그림으로 볼 수 있어요.

## 문제 해결

| 증상 | 이렇게 해 보세요 |
|---|---|
| "집 안을 불러오는 중이에요…"가 오래 떠 있어요 | 3D 파일이 커서 처음엔 시간이 걸려요. 와이파이에서 10~30초 기다려 주세요. 🧪 |
| 첫 접속이 1분쯤 걸려요 | 무료 서버라 15분 동안 아무도 안 들어오면 잠들어요. 처음 한 번만 느려요. ✅ |
| 화면이 검게 나오거나 깨져요 | 최신 크롬 · 사파리 · 엣지로 열어 주세요. 오래된 기기는 WebGL을 지원하지 않을 수 있어요. 🧪 |
| 키보드로 안 움직여요 | 3D 화면을 한 번 눌러서 선택한 뒤 키를 눌러 주세요. ✅ |
| 휴대폰에서 버벅여요 | 다른 앱을 닫거나 PC에서 열어 보세요. 🧪 |
| 길을 잃었어요 | **처음 위치** 버튼을 눌러요. ✅ |

## 주의할 점 🧪

- 3D는 촬영 시점의 모습이에요. 가구 · 소품은 실제 입주 때와 다를 수 있어요.
- 크기는 대략적인 참고용이에요. 정확한 면적은 매물 정보의 ㎡를 봐 주세요.
- 3D로 보고 마음에 들면 **실제 방문도 꼭** 해 보시길 권해요. (소음 · 냄새 · 수압은 3D로 알 수 없어요)
