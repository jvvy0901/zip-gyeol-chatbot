## 챗봇이 매물을 추천할 때 ✅

목록 화면 필터와 같은 기준으로 고르면 결과가 화면과 어긋나지 않아요.

- 지역 → `region` 이 정확히 같은 매물
- 거래 유형 → `deal_type` 이 같은 매물
- 예산 → `price`(보증금 · 매매가)가 예산 이하
- 방 수 → `rooms` 가 원하는 수 이상

추천할 때는 매물 링크(`/listings/번호`)와 같은 조건의 목록 링크(`/listings?region=...`)를 함께 알려 줘요.
